# Pathophysiology 3-Day MCQ Sprint

A self-contained offline MCQ website created for a 3-day university Pathophysiology exam sprint.

## Contents
- 150 original MCQs
- 123-question university recommended list used as the backbone
- Additional high-yield questions beyond the list
- Topic filters
- High-yield mode
- Recommended-list mode
- Wrong-question persistence with localStorage
- Mark/review support
- No backend or dependencies

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Open the generated Pages URL on your phone or computer.

The app is intentionally a single HTML file so it can run on GitHub Pages without a build process.
